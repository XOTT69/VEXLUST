# VEXLUST

Україномовний 18+ каталог інтимних товарів із Next.js 16, Neon PostgreSQL та інтеграціями. **Продажі та реальні платежі наразі вимкнені.**

## Реалізовано
- Повний імпорт каталогу SexOpt, щоденний захищений cron-синхронізатор, сторінки товарів, галереї, пошук, сортування, бренди та ціни.
- Дрібні товарні категорії й рекомендації за типом, описом, брендом, характеристиками та ціною.
- Кошик, обране, тестове оформлення з вибором Нової пошти, локальні чернетки.
- Neon Auth для реєстрації й входу, кабінет покупця.
- Захищена модель серверних заявок із перевіркою вартості, **не активована**.

## Локально
Node 20+, `npm install`, `npm run test`, `npm run dev`.

## Система
Neon DB використовує `DATABASE_URL`. Міграції запускаються під час prebuild. `CRON_SECRET` захищає `/api/cron/sync` (щодня 03:15 UTC). Для Нової пошти потрібен `NOVAPOSHTA_API_KEY`.

**Детальні кроки запуску й правові передумови**: [docs/LAUNCH.md](docs/LAUNCH.md).
